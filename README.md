# Pi Atlas

System for exploring pi as digits, text, colors and pixels.

Currently a 62,831,853,071 digit (τ * 10¹⁰) database that is over 24.6 GB after compression into .ycd
Computed by a single Acer TravelMate computer taking just around 1.38 days ;)

I would need more powerful computers to make a bigger database as the temporal data used for Chudnovsky gets heavy and QUICKLY

If the API is unconfigured or offline, the interface clearly labels its 100K fallback sample.
The full dataset is available only when the configured backend is online.

disclaimer: this website is made by AI as i have literally no HTML skills but all digits were locally computed.

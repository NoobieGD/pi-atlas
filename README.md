# Pi Atlas

Static frontend for searching and exploring pi as digits, text, colors and pixels.

Configure the permanent public HTTPS API origin in `config.js` before publishing.
This folder's contents belong at the root of the GitHub Pages repository.

The full 27,182,818,284-digit file belongs on the separate backend server, not in GitHub.
Visitors do not need to install Python, run a server, or open a local file.

If the API is unconfigured or offline, the interface clearly labels its 100K fallback sample.
The full dataset is available only when the configured backend is online.
